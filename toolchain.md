# Toolchain

| Program | How to install | Why here | Source |
| --- | --- | --- | --- |
| git | system package | Version control | https://git-scm.com |
| ketch | see the ketch README | Installs a manifest from `~/.ketch/manifests` before it is contributed here | https://github.com/pyrlyn/ketch |

No package manager is used by this repo. Each package is one `ketch.toml`.
